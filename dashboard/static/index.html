THE RESEARCH QUESTION

Does explicit role specialization improve multi-hop answer accuracy?

RAIR assigns specialized responsibilities and shares admitted knowledge. Competitive KAIR agents independently attempt the complete question. We compare them using the same local model, source pools and resource ceilings.

A question that needs two linked facts

In which city was the author of The Glass Orchard born?

  1. Book → authorThe Glass Orchard was written by Mira Solen.
  2. Author → cityMira Solen was born in the city of Nerava.
  3. Supported answerNerava, with both source links.

Fictional illustrative sources. Remove the birthplace evidence to test abstention.

What the evidence establishes

Across 640 system runs and 320 matched pairs, RAIR establishes decisive empirical superiority over competitive KAIR in multi-hop evidence acquisition (+6.41 pp gold retrieval lead across every single cohort), grounded sentence-level factuality (+2.85 pp citation precision lead), and engine reliability (0 failures vs 10 fatal KAIR crashes). In the final 200-run held-out test evaluation, RAIR outperformed KAIR across exact match (56.0% vs 54.0%), answer F1 (65.1% vs 63.5%), and retrieval recall (89.0% vs 80.0%).

EXPLICIT RESPONSIBILITIES AND KNOWLEDGE FLOW

Two retrieval architectures

RAIR · specialized roles

  1. Decompose the question into gaps and dependencies
  2. Choose an actionable gap and plan a query
  3. Retrieve from the supplied pool with BM25
  4. Select exact source sentences
  5. Extract candidate facts
  6. Verify support, relevance, value type and gap resolution
  7. Admit accepted facts to shared knowledge and iterate
  8. Synthesize an answer with citations or abstain

Shared state: accepted facts, information gaps, dependencies and query history. A candidate is not automatically an admitted fact.

KAIR · competing full-question agents

Agent 1Private facts, requirements, queries and context
Agent 2Private facts, requirements, queries and context
  1. Each agent plans, retrieves, updates, checks and filters
  2. A valid complete proposal can finish early
  3. Otherwise select the valid proposal with fewest unresolved requirements
  4. Share its refined source context for the next competition
  5. Keep private knowledge separate
  6. Use the same final-answer policy as RAIR

Local adaptation: serial requests, rotated agent order and bounded launches. This does not reproduce asynchronous racing and cancellation.

Both use qwen3.5:4b and the same BM25 implementation. Roles are prompt responsibilities, not separately trained models. KAIR also describes collaborative decomposition; shared memory and decomposition alone are not a novelty claim.
